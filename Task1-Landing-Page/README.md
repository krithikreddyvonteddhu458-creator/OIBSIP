# Task 1: Landing Page (Nova Productivity)

A responsive, modern landing page designed for **Nova**, a productivity platform built to help users manage tasks, organize projects, and stay focused.

---

## 🌟 Features

* **Hero Section**: Strong call-to-action (CTA) with an interactive task progress card preview.
* **Feature Showcase**: Responsive grid highlighting key features like Task Management, Progress Tracking, and Focus Tools.
* **About Section**: Detailed background information with visual design elements.
* **Testimonials**: Social proof featuring feedback from real users.
* **Sticky Navigation**: Clean header with smooth scrolling to relevant sections.
* **Fully Responsive**: Mobile-first media queries ensuring seamless display across mobile, tablet, and desktop viewports.

---

## 🛠️ Built With

* **HTML5**: Semantic elements (`<nav>`, `<section>`, `<footer>`) for improved structure and accessibility.
* **CSS3**: Custom properties, modern CSS Grid, Flexbox layouts, and `@media` queries for dynamic responsiveness.
