# Task 3: Temperature Converter

A simple, interactive web application that instantly converts temperatures between **Celsius**, **Fahrenheit**, and **Kelvin**.

---

## 🌟 Features

* **Multi-Unit Conversion**: Convert values seamless across Celsius, Fahrenheit, and Kelvin scale measurements[cite: 5].
* **Input Validation**: Displays clear error messages if input fields are empty or non-numeric[cite: 6].
* **Physical Boundary Check**: Prevents inputs that fall below absolute zero ($-273.15^\circ\text{C}$)[cite: 6].
* **Formatted Output**: Results are rounded to 2 decimal places with clear unit formatting[cite: 6].
* **Responsive Card UI**: Centered container layout optimized for both desktop and mobile devices[cite: 7].

---

## 🛠️ Tech Stack

* **HTML5**: Form inputs, select dropdowns, and semantic markup[cite: 5].
* **CSS3**: Flexbox centering, customized focused state inputs, and mobile responsiveness[cite: 7].
* **JavaScript (ES6)**: Real-time user input parsing, mathematical conversion algorithms, and DOM updates[cite: 6].
