# Task 2: Personal Portfolio Website

A clean, modern, and responsive personal portfolio website built for **Vontedu Krithik Reddy**, a Computer Science Engineering student.

---

## 🌟 Features

* **Hero Section**: Introduces basic details and technical background alongside a avatar badge.
* **About Me**: Brief overview of academic background, technical interests, and expertise.
* **Technical Skills Grid**: Responsive grid displaying proficiency across programming languages, web technologies, databases, and AI/ML frameworks.
* **Projects Showcase**: Interactive cards featuring past work including Image Caption Generator, Student Attendance System, and Web Apps with tech stack tags and links.
* **Contact Section**: Direct links for email inquiries, GitHub profile, and LinkedIn network connections.
* **Sticky Navigation**: Fixed navigation header enabling effortless jumping between page sections.
* **Responsive Layout**: Media query rules for optimized viewing across smartphones, tablets, and desktop devices.

---

## 🛠️ Tech Stack

* **HTML5**: Structured semantic markup for clarity and SEO friendliness.
* **CSS3**: Layout design using CSS Grid, Flexbox, interactive hover states, and dynamic responsive breakpoints.
